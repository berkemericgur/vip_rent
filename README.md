<h1 align="center" id="title">VIP Rent</h1>

<p align="center"><img src="https://socialify.git.ci/berkemericgur/vip_rent/image?font=Raleway&amp;language=1&amp;name=1&amp;owner=1&amp;pattern=Formal+Invitation&amp;stargazers=1&amp;theme=Auto" alt="project-image"></p>

<p id="description">VIP Rent lüks araç kiralama hizmetleri sunan bir platformdur. Bu proje müşterilerin premium araçları kolaylıkla kiralamasını sağlayan bir sistem geliştirmeyi amaçlamaktadır.</p>

  
  
<h2>🧐 Features</h2>

Here're some of the project's best features:

*   Araç Yönetimi: Yeni araç ekleme mevcut araçları güncelleme ve silme.
*   Müşteri Yönetimi: Müşteri bilgilerini ekleme güncelleme ve silme.
*   Rezervasyon Sistemi: Müşterilerin araç rezervasyonu yapabilmesi.
*   Ödeme Entegrasyonu: Güvenli ödeme işlemleri.
*   Raporlama: Kiralama ve gelir raporları oluşturma.

<h2>🛠️ Installation Steps:</h2>

<p>1. Depoyu Klonlayın:</p>

```
git clone https://github.com/berkemericgur/vip_rent.git cd vip_rent
```

<p>2. Gerekli Bağımlılıkları Yükleyin. Maven kullanarak proje bağımlılıklarını yükleyin:</p>

```
./mvnw clean install
```

<p>3. Veritabanı Yapılandırması: PostgreSQL kullanıyorsanız application.properties dosyasında veritabanı bağlantı ayarlarını yapın.</p>

```
spring.datasource.url=jdbc:postgresql://localhost:5432/vip_rent spring.datasource.username=your_username spring.datasource.password=your_password
```

<p>4. Uygulamayı Başlatın: Uygulama varsayılan olarak http://localhost:8080 adresinde çalışacaktır.</p>

```
./mvnw spring-boot:run
```
